- `crates/xlsxdown-node` (cdylib, napi; publishes `@d0paminedriven/xlsxdown`): `src/lib.rs` (class `XlsxDown { constructor, static openAsync, spreadsheetCells, spreadsheetCellsAsync }` plus free `spreadsheetCells` / `spreadsheetCellsAsync`; `Arc<Workbook>` shared with tasks), `src/types.rs` (napi shapes, `sheet_cell!` macro), `src/cells.rs` (+ `cells/tests.rs`).

Behaviour changes versus pdfdown, all deliberate and accepted by Andrew: followers of a shared formula carry `formula` (master's text moved) plus `sharedFormula`; a clock-only format on a serial >= 1 yields a date-time, not a bare time; built-in ids 27-36 and 50-58 are dates; stricter `$` handling in cell refs. Dates are zone-free ISO, 24-hour (`YYYY-MM-DD`, `YYYY-MM-DDTHH:MM:SS`, `HH:MM:SS`): mirror the source format, never assume UTC.

Verified earlier against pdfdown's saved output for the private corpus (31 files, 168,801 cells): only the intended differences (1,247 follower formulas; 9,872 `mmss.0` cells now dates), and all expanded formulas match openpyxl.

Not ported (stays in pdfdown until a layout crate exists): `detect` / format sniffing, `project()` onto `PageLayout`.

```ts

// delete: the node:fs import, readManifest(), napiTargets()
```
