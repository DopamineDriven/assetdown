## Conventions that bit or mattered this session

- Never run cargo with the working directory inside a reference repo (`~/reference/pdfluent-sdk`,
  `~/rust/napi-rs`): rustup installs the pinned toolchain and cargo rewrites `Cargo.lock`. Use the
  scratchpad, `--locked` and a scratch `CARGO_TARGET_DIR`.
- Shared Rust crates are fine with Andrew when they hold no format-specific code and add nothing to
  install; extra npm packages per feature are not. xlsx logic lives only in `xlsxdown`; the pdf crates
  carry no xlsx references.
- `rustfmt.toml` has `trailing_comma = "Never"`, nightly-only. Stable ignores it with a warning, so
  formatted code keeps trailing commas. Andrew dislikes them; if he installs nightly rustfmt,
  reformat with `cargo +nightly fmt`.
- `crates/pdfdown-node/Cargo.toml` has a `[profile.release]` table that Cargo ignores with a warning.
- Clippy's `upper_case_acronyms` fires on mirror enums (`UBL`, `DMY`) in a private module; the
  bindings export their `invoice` module publicly to avoid a lint exception.
- An async method only gets a typed promise when its `Task` impl is in the same crate.
- Generator scripts for the mirror types are in the session scratchpad under `gen/` (not in the repo):
  `invoice_mirror.py`, `port_node_types.py`, `port_node_lib.py`, `port_pdfdown.py`.
