## Decisions that bind the design (Andrew's)

- **Pure MIME.** An answer has `mime` and `topLevel`. No `IMAGE`/`DOCUMENT` kind in `mimedown`; he maps types to his own enum in TypeScript. Do not reintroduce a kind.
- Never a MIME type as an argument; no guessed-type field; unknown is an answer, not an error; the file name is a hint for text only.
- Libraries have no napi; each npm package is a `<name>-node` crate. Manifests, `package.json`, napi config, `.gitignore`, releases are his: propose, do not edit. No new third-party dependency without his say.
- No new fixtures unless he adds them; build files in tests, or make real ones in scratch with the tools listed in memory.
- American spelling. Tests on the `WorkupService` classes in TypeScript. His CLAUDE.md TypeScript rules apply to every `.ts` I write (no `any`, no `enum`, `satisfies` over `as`, `Array.of<T>()`, no `console.log`).
