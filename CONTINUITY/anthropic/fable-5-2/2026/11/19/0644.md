## Conventions and standing rules

- Rust 2024, two-space indent, `cargo fmt`, clippy with `-D warnings` in every feature set; tests beside code as `<module>/tests.rs`; test names are sentences; checked conversions over `as`; enums with payloads. Test first: watch each test fail before the code that satisfies it, and say plainly where that did not hold.
- **Oxford commas always** in prose lists of three or more (descriptions, comments, messages, notes, chat). Code never takes a trailing comma in TypeScript.
- **Fidelity before performance**: the parsers run in the background; completeness beats speed; a cap only guards against damaged or hostile input, sits far above anything real, and warns when hit.
- **Versions**: each release is the next minor, and 0.9.0 is followed by 0.10.0. Releases and commits are the user's (`./version.sh <package> <version>`, commit subject `<package>@<version>`).
- Manifests (`Cargo.toml`, `package.json`), napi configuration, and `.gitignore` are the user's: put the desired manifest in the plan file and let them create the crate. A one-line addition they have asked for or that a documented step needs has been accepted; say so when made.
- No new fixtures unless the user adds them; make real files in scratch with `magick`, `tiffcp`, `soffice`, `ffmpeg`, and check against `tiffdump`, `tiffinfo`, `pdfinfo`, `exiftool`.
- Nothing from any `__test__/fixtures/private` folder, from `notes/`, or from the user's CDN list is named, quoted, or counted here. Keep it that way in every tracked file, this folder included: such files are read in place, aggregated locally, and reported as figures in chat only. Do not run the fetch scripts that fill those folders.
- Throwaway programs go in `crates/<crate>/examples/` only while in use, and scratch data in the session scratchpad; delete both. `rm` with a relative glob after `cd` is refused by a safety check: remove by full path.
- TypeScript: the rules in `CLAUDE.md` (no `any`, no `enum`, `satisfies` over `as`, `Array.of<T>()`, no `console.log` in tests, node:test through tsx, yarn 4, tests on `WorkupService` classes).
- CI: each binding has `ci/` composite actions and a thin workflow; lint jobs without Tesseract exclude `pdfdown-ocr` and `ocrdown`.
- A harness trap: in a Bash here-document a backslash, `u`, and four hex digits become that character. And a Python patch script anchored on text written before `cargo fmt` can miss; read the current text first.
