### Things about the code worth knowing

- `xlsdown`: a formula cell has `formula: Some("")`, because the text of a formula is not read; a follower of a shared formula has `shared_master`. A chart's records nested in a sheet are skipped by counting openings and ends.
- `docdown::pieces::Unit` is one to each UTF-16 unit, so an index into the units is a character position, which is what the tables of headers, text boxes, and anchors count in.
- `docdown::body::blocks(units, source, boxes)`: `boxes` is `Some` only for the document's own text. The last stretch the text-box table lists is the mark that ends the boxes' text, not a box.
- `contentdown::document::Placing::down_from` is `DownFrom::{PageTop, TopMargin, Text}`. `rtfdown` sets the first two; it could set `Text` for `\pvpara`, which it does not read yet.
- `cfbdown::CompoundFile::storage(path)` hands a storage back as a compound file, which is how an embedded workbook comes out of a `.doc`.
